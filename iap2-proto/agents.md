This is a repository of an iap2 protocol implementation, developed only via
clean-room reverse engineering, building upon prior reverse engineered work,
interrogating ai, and now vibe coding. It is focused on emulating the iphone
carplay side of the protocol, as the goal is to connect this code to a carplay
head unit, though it should be architected in such a way that the code is
asymetric.

The ops folder is to contain all iap2 operations based on different control
bytes, eg switch to iap2, reset, get wifi credentials, etc.
